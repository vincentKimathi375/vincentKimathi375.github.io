VINCENT KIMATHI PETER — PROFESSIONAL ICT PORTFOLIO

This is a multi-page static website. Each navigation item opens a separate HTML page:
- index.html (Home)
- about.html
- skills.html
- experience.html
- education.html
- projects.html
- contact.html

PROJECT STRUCTURE
assets/css/style.css  - shared styling
assets/js/main.js    - mobile navigation and footer year
assets/images/       - place profile image or project images here
assets/documents/    - place public CV PDF here if you want to add a CV link

RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open index.html and open it in your browser.
4. Click the navigation links to move between pages.

BEFORE PUBLISHING
- Replace the contact placeholders in contact.html with details you want public.
- Verify education wording and dates against official documents.
- Verify role titles and dates in experience.html.
- Only describe projects as completed after you have built them.
- Add a real professional photo only if you want one.
- Do not upload passwords, ID numbers, private documents or sensitive information.

GITHUB PAGES
Create a public repository named exactly: vincentKimathi375.github.io
Upload the contents of this folder (not the ZIP file itself) to the repository root.
In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
Your site should publish at https://vincentKimathi375.github.io after deployment completes.
